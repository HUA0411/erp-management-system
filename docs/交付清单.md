# 交付清单（交付给客户时参考）

本文档列出售卖/交付源码时需要交付的全部内容与验收步骤。

## 一、交付物清单

| 类别 | 内容 | 说明 |
|---|---|---|
| 源码 | 完整仓库（server / web / shared） | 前端 Vue3 + TS，后端 NestJS + TS，共享类型包 |
| 数据库脚本 | TypeORM 迁移（`server/src/database/migrations/`） | 建表结构，无需手写 SQL |
| 初始化脚本 | `npm run db:init` / `db:reset` / `db:demo` | 一键建库、清空业务数据、恢复演示数据 |
| 配置文件 | `server/.env.example`、`server/.env`（示例值） | 客户需自行填写数据库连接与 JWT 密钥 |
| 部署文档 | `docs/部署指南.md` | Windows / Linux 生产部署 |
| 定制文档 | `docs/定制开发指南.md` | 品牌/界面/功能定制 |
| 授权文档 | `docs/授权协议模板.md` | 双方授权范围与限制 |
| 接口文档 | Swagger（`/api/docs`） | 部署后可在线查看 |

## 二、环境要求（告知客户）

- Node.js ≥ 20
- MySQL 8.0（建议 utf8mb4）
- 内存 ≥ 1GB（推荐 2GB，单实例可承载几百用户）

## 三、交接验收步骤（建议按此演示/验收）

1. 客户环境安装 Node 与 MySQL，创建数据库账号
2. 修改 `server/.env` 数据库连接与 `JWT_SECRET`
3. 执行 `npm install` → `npm run db:init` → `npm run dev`
4. 用 `DEMO / admin / 123456` 登录，走查：采购订单→确认→入库→库存增加→销售订单→确认→出库→库存减少→收付款→应收应付→看板联动
5. 若客户要干净起步：执行 `npm run db:reset`（清空演示业务数据，保留权限/角色/用户模板）
6. 交付演示账号清单：admin/123456（超管）、zhangsan（采购）、lisi（销售）、wangwu（仓管）、zhaoliu（财务）

## 四、交付时注意事项

- **务必提醒客户修改 `JWT_SECRET`** 与默认密码，正式上线前改 `admin` 密码
- 数据库账号建议为专用账号（不要用 root）
- 源码授权范围以《授权协议模板》为准，明确是否允许二次分发/转让
- 演示数据仅用于演示，`db:reset` 后客户录入真实数据
